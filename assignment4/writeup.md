I used a `GradientBoostingRegressor` because corn yield is a continuous target and tree ensembles handle the nonlinear relationships between weather/vegetation and yield well -- the same model family the broader crop-yield-prediction project already validated against real NASS county yields via leave-one-year-out cross-validation. The pipeline predicts corn yield (bu/acre) for a county-year from NDVI, weather, heat/drought stress, and soil/terrain inputs. My custom transformer, `CountyAnomalyTransformer`, learns each county's own multi-year baseline for the dynamic features at fit time and re-expresses new rows as anomalies from that baseline plus a year-trend term, since what predicts a yield swing is how unusual a season is *for that specific county*, not the raw value. That learned state (each county's fitted mean) is why the pipeline has to be loaded from the saved artifact rather than rebuilt fresh -- a new transformer has no county means at all. Built with scikit-learn 1.9.0, trained on 4,699 real county-year rows across 341 counties.
